# Day 16 — Countdown Timer

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A countdown timer to any future date and time with
multiple saved countdowns and live ticking display.

## How to view
Open `index.html` in your browser.

## Features
- Count down to any custom date and time
- Shows days, hours, minutes, seconds live
- Save multiple countdowns
- Expired countdown detection
- Clean dark UI
